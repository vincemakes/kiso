## 1. #14 (P1) — the idle heartbeat painted with zero change

Measured: 12s idle = 61 re-paint copies / ~47KB (the repro in this
round: 73,813 bytes). The 200ms heartbeat re-rendered the whole body
and re-painted the dock's three rows (including the 80-char ╌ row)
even though NOTHING had changed — and the same re-push tore the native
scrollback. Fix:

- **The idle heartbeat paints NOTHING**: a beat only matters when an
  ACTIVE cell exists (a running/approval tail with glyph/elapsed to
  advance); an all-frozen body returns without scheduling a frame.
- **重绘≠重推** is the standing rule: on-screen rows are only ever
  overwritten in place with CUP; a REAL LF (scroll) happens ONLY when a
  NEW frozen line first lands. The heartbeat never pushes.
- The new **idle-probe gate** (`idle-probe.test.ts`, permanent): one
  round, then ≥8s of silence — the idle window stays <2KB (was ~73KB),
  the terminal response appears EXACTLY once, the window contains no
  LF (zero scroll) and no dangling CSI.

## 2. v3 — the design landing (§01-§05, per the ruling's summary)

- **§01 banner**: block-split — three independent logo rows (TOP /
  tagline / BOTTOM), then TWO info rows (version, extensions). Every
  row truncates at the window width with a " (+N)" marker (N = hidden
  display width); a window narrower than 40 columns skips the logo.
  (A pty without a winsize reports columns = 0 — treated as the
  default width, never a 0-column truncation: the banner test caught
  the " (+7)" collapse.)
- **§02 user block**: the user message is an SGR background block
  (`48;5;237`), no "you> " prefix — multi-line whole, resize-safe
  (per-line truncation). The thinking fold's hint is "(N chars ·
  /think)". The **recap line** ends every run: `▞ 47s · 3 tools
  (1 edit) · in 8.2k out 410 · cache 97% · ctx left ~96%` — all
  fields derived LOCALLY from the run's event stream (zero tokens):
  wall seconds, tool/edit counts, usage (k-units), cache hit %,
  ctx-left %. It replaces the old "done" label + status line (pipes
  get the same line in plain text).
- **§03 dock**: four rows — upper ╌ / input / lower ╌ / status. The
  status line has two states: idle `▸ <mode> · /mode to switch ·
  <model> · ctx left ~N%` (default shown too), running `▖ working Ns ·
  ↓ N tokens · esc to interrupt · ctx left ~N%` with the ▖▘▝▗ 200ms
  rotation (the spinner now drives the running status line).
- **§04 slash-command menu**: typing "/" opens it (TTY only), prefix
  filtering over the command table (/mode /think /last /status /help
  with English one-liners), ↑↓ select, Tab completes, Enter submits
  the selection, Esc cancels. Drawn above the chrome.
- **§05 glyph family & palette**: ▞ recap · ▖▘▝▗ working · ▸ idle ·
  ▌ brick · ╌ separators · ▎ diff edge; the palette gains `bg`
  (SGR 48). All UI copy is English (i18n out of scope).

## 3. Test updates (the replaced assertions, listed per the spec)

The recap replaced the done label + the status line, the user block
lost its prefix, the dock grew a row, and the status line changed —
every affected assertion was updated with its v3 form:

- `[turn N · faux]` status → the recap line `▞ Ns · N tools?` (e2e,
  microcompact, v2a, v2b feeds).
- `you> <text>` body echo → the SGR background block (body, v2b, v2c).
- "… /think shows full" → "(N chars · /think)" (render-safety, body,

## 6b. #15 (P2) — the idle-skip criterion is "no change", not "all frozen"

The #14 skip (all-frozen) still re-painted on a short session: ANY
unfinished cell (an unclosed text/thinking block) kept the criterion
true, so the beat re-rendered the tail AND the dock (the ~1KB dock
repaint is the leak's body — measured by the user: 51KB / 46 beats
after the recap, LF=0). Fix: the beat advances ANIMATION only — a
RUNNING tool's glyph/elapsed is the only thing that changes between
beats; no animation → the beat paints NOTHING, frozen or not.

The idle probe grew the second scenario (a text-only round, screen
never full) with the same <2KB / exactly-once / no-LF / no-dangling-CSI
assertions. Honest limitation: the PTY reproductions stay under the
2KB gate even on the old criterion (the body's cell-closing paths all
work under PTY — the user's 51KB needs a cell-residue shape PTY cannot
produce), so the red side of this probe could not be demonstrated in
the suite; the criterion fix stands on its semantics and the probes
guard both scenarios permanently. Zero net src lines (the gate holds
at 2325/2400).
