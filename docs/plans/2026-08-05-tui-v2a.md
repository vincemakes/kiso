## 1. The four defects (from real-machine transcripts)

1. **双回显**: in interactive chat the line the human just typed was
   rendered AGAIN by the user_input event (readline had already echoed
   it). Fix: live-typed input's echo belongs to readline; the event
   render stays for the REPLAY paths (recovery, resume — nobody typed).
   The determination is deterministic — exact content match with the
   line THIS process's readline consumed, on a TTY (the only place an
   echo exists to hand over) — never a guess. The ref binds to the
   TURN's own input (a line that arrives ahead of its turn must not
   overwrite it).
2. **色彩身份**: kiso had no identity — GREEN/YELLOW/CYAN scattered.
   v2a: ONE accent — blue, ANSI 256 color 75 — for the you> prompt, the
   banner tagline, ✓ marks, and slash-command names; red for errors;
   dim for metadata; everything else plain. The palette lives at the
   top of render.ts, no hard-coded codes elsewhere. NO_COLOR or a
   non-TTY output → the EMPTY palette: pipes carry zero ANSI (the
   byte-level e2e assertions guard it).
3. **状态行降噪**: unknown (?) fields are omitted ENTIRELY (有什么显
   什么); a fully-unknown usage → the whole line is omitted; faux mode
   shows `[turn N · faux]`. Real-provider output with all fields known
   is byte-identical to before (existing assertion re-verified).
4. **节奏规范**: exactly one blank line before every user turn start;
   summaries run together without blanks; the status line hugs the
   terminal; one blank after the status, then the prompt. Pinned by a
   render test (渲染序列→期望字节 — the consumer's exact composition).

## 2. Findings during the round

- **A real exit bug (pre-existing, PTY-only)**: the CLI sometimes never
  exited after the REPL closed — readline leaves the stdio handles
  active and the natural drain is RACY on a TTY (measured: identical
  shapes flipped between exit and hang across runs; the process was
  genuinely alive, not a zombie — reaped with waitpid(WNOHANG)). The
  十 natural-drain design assumed drain always works; on a TTY it
  doesn't. Fix: explicit `process.exit` AFTER main's finally has run
  (agent.close, dispose, temp cleanup — nothing skipped, no lock left
  behind). The tui-v2a PTY e2e dropped from 40s (driver timeout) to
  158ms.
- The colored prompt (ANSI inside rl.setPrompt) is SAFE on node 22 —
  verified with a pty probe: readline strips the codes for cursor math
  and redraws correctly through backspaces.
- The pipe byte diff (acceptance ③) contains ONLY the declared
  differences: zero ANSI (§2), the input-render kept in pipe mode (the
  echo filter is TTY-gated — pipe transcripts keep the `you> <input>`
  annotation), the status line's faux form + position (§3+§4).
