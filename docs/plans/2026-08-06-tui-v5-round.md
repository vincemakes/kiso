## #16g dock status row: the right-aligned dim hint

- `#statusRow(status, p, W)`: in the idle state (tail empty, no
  takeover question) the row right-aligns `/ commands · ↑ history`
  (dim, the same span); a short width cuts the hint FIRST (the status
  itself is never truncated for it); the running state carries its own
  esc hint → suppressed whenever the tail is non-empty; a takeover
  question replaces the whole row. A new permanent PTY gate (merged
  into the storm file): at 80 columns the hint appears; at 50 columns
  the hint is cut and the status is untouched (asserts the dim span
  ends exactly at the status's end + the status renders from column
  1).
