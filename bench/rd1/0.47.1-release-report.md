# 0.47.1 — release report (APPROVED)

0.47.0's polish, cut from `v0.47.0` onto `release/0.47.x` (`main` already
carries later work). Four changes, each merged into `release/0.47.x`
through its own PR with `check` and `windows` green; this release adds only
the version bump. The owner approved the round on 2026-10-07 and
2026-10-08. This session runs the round, and the Task/Inbox session reviews
it independently.

- **Candidate:** 17 tarballs packed from the release branch's head (every
  `dist` deleted and rebuilt first; the publishable list derived from the
  workspaces), installed isolated. The release smoke and the kill -9 demo
  ran on them.
- **Lockstep:** cosmetic fixes and a re-tuned dark palette → a PATCH under
  0.x; 17 packages.
- **Kernel:** 2,192 / 2,200 lines, unchanged.

## What is in it

| PR | what changed |
|---|---|
| #265 | **The polish** (findings 0470-F1 to F4 from the agent's 0.47.0 dogfood). A cut note counts output lines, the unit it names, and says when the cut passes through a line (`… the start of this line`). Manual `/compact` on a dock no longer draws the raw `[summarized up to seq N]` under its `COMPACTED` row, which reads `1 round` for one. A refusal the person gave no words for reads `denied by you` alone, with no body repeating it and no `approval cancelled` row |
| #269 | **24-bit colour where the terminal is known to render it.** Windows Terminal renders 24-bit and does not set `COLORTERM`; kiso drew it in the 256 tier, where the person's cream block became pink and its gold edge olive. Windows Terminal (`WT_SESSION`), iTerm2, WezTerm, Ghostty, kitty, VS Code, Warp, Alacritty, JetBrains and any Windows console now get 24-bit; inside tmux or screen only `COLORTERM` counts |
| #273 | **The dark table re-adapted** (the owner's preset D on the dark palette page). Card surfaces, the selected row, code, diff rows and the meter's track rise a step on a black ground; `dim` and `ink2` rise with them, and every text pair still clears 4.5:1 in both tiers. A light ground's surfaces now derive from the white column alone (the shared map had pulled a card on `#eeeeee` to within 1.09:1 of its ground) |
| #275 | **The dark hairlines** rise to `#656565` (the owner's pick): the composer's rules and every header rule read too grey on Apple Terminal's Pro profile |
