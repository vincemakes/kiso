# 0.53.0 — release report (APPROVED)

**Sessions can be forked, titled and continued: `/fork`, the session title and the follow-up suggestion, in the
terminal and in kiso web.**

**Runtime (#387):**
- `SessionStore.fork(parent, { afterSeq? })` copies a session's log up to a reply's terminal and records the lineage
  in the fork's `.meta.json` (`forkedFrom`);
- `Session.followUp(options?)` and `Session.title()` each send one side request, only when a host calls them;
- the public surface grows from 50 to 53 names: `FollowUpOptions`, `ForkOrigin` and `ForkRefusedError`.

**Terminal:**
- the session title, timed out at 15 s (#383);
- the follow-up suggestion as a ghost in the empty box, which Tab takes (#385);
- `/fork` (#388);
- the title needs a TTY, so a piped chat never sends one (#389).

**Web (#362–#386):** the header, the composer, sidebar tabs, pins, menus and the session tree, fork, follow-ups,
titles, attachments, and fixes.

**The release itself:**
- **Candidate:** PR #390, merged as `b15d697c`; the annotated tag `v0.53.0` points at `c7faab1e`.
- **Kernel:** unchanged. The tools, the providers and the system prompt are unchanged.
- **Unchanged bytes:** the premise probe found the same 9,564-byte first request on 0.52.0 and 0.53.0.

## For hosts

- **New runtime methods (no change unless called):** `SessionStore.fork`, `Session.followUp` and `Session.title`.
  - `fork` refuses with `ForkRefusedError` when `afterSeq` is not a terminal.
  - The fork note is added to the fork's first real input, after the copied history, so the parent's cache prefix
    holds. No session's system prompt changes.
- **The terminal sends two new side requests, interactive only:**
  - the session title, one request after the first message; it needs a TTY, so a piped chat and `kiso -p` never
    send it; off with `KISO_AUTO_TITLE=off`;
  - the follow-up suggestion, one request after a completed reply; off with `KISO_FOLLOWUP=off`.
- **`kiso web` sends side requests too:** titles (off with `KISO_AUTO_TITLE=off`) and follow-ups (off with
  `KISO_WEB_FOLLOWUP=off`).
- **`/fork`** lists the session's replies and forks after the one picked; the terminal switches to the fork, named
  "… (fork)". The original stays in `/resume`.
- **The `/help` list has one more row** (28 rows), for hosts that match on it.
- **Action required:** none.
