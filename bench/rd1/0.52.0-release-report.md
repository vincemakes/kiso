# 0.52.0 — release report (APPROVED)

**kiso web ships as the 18th lockstep package, and four tool fixes change what a model sees.**

**The web UI.** `@vincemakes/kiso-web` (macOS and Linux) carries the web UI (#354–#358).
- Install it with `npm i -g @vincemakes/kiso-web`, then run `kiso web` or `kiso-web`.
- Without it, `kiso web` prints that install line and exits 1.

**Tools:**
- `write_file` creates parent directories (#350);
- replacing an existing file needs a whole-file read first, and the refusal says how (#351);
- a shell timeout returns the output so far (#352);
- a command whose process exited while a child kept its output open now returns, with a note saying so, instead of
  hanging the call (#353).

**Hosts:**
- runtime task exports and `runsACheck` (#336, #340);
- the `./policy` and `./config` doors of kiso-code (#337, #341, #344, #347);
- a per-session approval tier, `modeExtensions(workspaceRoot, currentTier)` (#346);
- the task runner's environment (#338).

**The release itself:**
- **Candidate:** `caf8a15c`, "chore: release 0.52.0", on main `07ae1fcc`; PR #360. The 18 tarballs were packed in a
  fresh worktree after `npm ci`.
- **Kernel:** unchanged.
- **Unchanged bytes:** the system prompt text, the tool schemas and the first request. The premise probe found the
  same 9,564-byte first request on 0.51.1 and 0.52.0.

**The rent gate stopped the run once.** In 3 of the 16 T6 pairs, rc's first request read 4 tokens less than ctl's.

- The owner ruled it an artefact of the provider's accounting, and the gate resumed. From the next release, the

## For hosts

- **`kiso web` changes meaning.** It starts the web UI, or prints the install line and exits 1. A session named
  `web` is now `kiso chat web`; `kiso -p "web …"` is unchanged.
- **The new package `@vincemakes/kiso-web`:**
  - `os` is darwin and linux;
  - its bin is `kiso-web`;
  - it pins eight `@vincemakes/*` packages at 0.52.0.
- **`modeExtensions(workspaceRoot, currentTier)`:** without the second argument the behaviour is unchanged.
- **Tool-result texts changed in #350–#353**, for hosts that match on them.
- **Action required:** none for the terminal. A host that wants the web UI installs kiso-web.
