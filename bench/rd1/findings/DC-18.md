# DC-18 — the model picker overruns its own height budget by two rows

- **id:** DC-18
- **class:** height budget
- **severity:** P2 — two rows of committed content scrolled into the
  scrollback, irreversibly, every time `/model` opens on a tight screen
- **agent:** kiso 0.16.4 working tree (introduced by this round)
- **found by:** an adversarial review counting the block's fixed rows
  against its budget
- **status:** FIXED (0.16.4 working tree)

## The measurement

```
maxRows= 6, 12 options → 8 rows emitted  (+2)
maxRows= 8, 12 options → 10 rows emitted (+2)
maxRows=10, 12 options → 12 rows emitted (+2)
```

```ts
// the budget: the header, the t row, the affordance and the rule
const budget = Math.max(1, maxRows - 4);
```

Four. The block pushes **five** unconditional rows: the opening rule
(added this round), the header, the t row, the affordance, and the
closing rule — plus a sixth, the `+N more` notice, whenever the option
list is longer than the window.

## The cause

The same commit that added the opening rule to this block bumped the ask
panel's chrome 5→6 and the approval panel's 5→6 to pay for exactly this,
and did not bump the pick panel's 4. Three sibling blocks, one change,
two of them accounted for.

It is not a crash: `liveCount` measures the block's real length, so the
frame is drawn correctly. What it costs is quieter and worse — the live
region is two rows shorter than the compositor was told, so two rows of
committed content are force-committed into the terminal's scrollback
before they needed to be, and that cannot be undone.

## The fix

`maxRows - 5`, and one more when the `+N more` row will appear.

## The same block, one column over

The unselected option rows carried a **two**-space prefix while
`selectionBar` spends one leading cell of its own — so the digit column
moved one cell as the cursor walked. The approval and ask panels both use
one space, for the reason this file states twice in its own comments:
*"a column that moves per row reads as damage, which is the R2 picker's
finding, inherited."* Fixed to one space on the option rows and the t
row.
