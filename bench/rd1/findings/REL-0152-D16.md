# REL-0152-D16 — the pasted image's path was sent to the command parser

- **id:** REL-0152-D16
- **class:** input / a feature that failed at its last step
- **severity:** P1 — the feature reached the end and produced an error
- **agent:** kiso 0.15.8
- **found by:** owner dogfood, 2026-08-26
- **status:** FIXED

## What happened

REL-0152-D15 made ctrl+V fetch the clipboard, and on the owner's machine
it WORKED — the coercion that failed from a detached shell succeeds
inside a real terminal session, which answers D11's open question. kiso
wrote the screenshot to a temp file and inserted its path.

The path begins with `/`. The composer handed it to the slash-command
dispatcher:

```
unknown command: /var/folders/rr/…/paste-89210-…png — /help lists the commands
```

A feature that reaches its last step and hands the result to the wrong
parser has not shipped. The reference implementation avoids it by
showing `[image1]`, and the shape was already in this file: D8's paste
capsule holds the content beside the buffer and shows a short token.

## The fix

`[Image #N]` in the buffer, the file in a map beside it. The token is
what the LINE carries, so the dispatcher sees something that is not a
command and never could be; the CLI resolves the number to the file when
it builds the turn.

Unlike the text capsule, an image is NOT expanded into the line on the
way out. A path is not something the model should be sent, and a
transcript full of temp-file names is not something a human should have
to read — so the capsule is the whole line, start to finish, and the
image rides beside it as a content block.

A number nobody registered, or one whose file has gone, stays as literal
text. That is the path route's rule and it is here for the same reason:
telling the model about a file it cannot see is worse than telling it
nothing.

## Evidence

- `packages/tui/tests/image-capsule.test.ts` — the capsule, the
  submitted line, the editor's map, words around it, two images,
  deletion, and a text paste still being a text capsule.
- `apps/cli/tests/attachments.test.ts` — the capsule resolving to an
  image block, and the three ways it stays literal text.
- Real PTY, ctrl+V with an image on the clipboard: the composer shows
  `[Image #1]` and no path appears anywhere in the capture.

## The lesson, again

D15's own finding said the D11 gates "tested the mechanism and not the
trigger". These tested the mechanism and not the DESTINATION: every case
asserted what the editor inserted, and none asked what happened to the
line afterwards. The feature was verified up to the boundary of the
module that owned it.
