# DC-12 — `▸` meant both "the current item" and "waiting on you"

- **id:** DC-12
- **class:** mark vocabulary
- **severity:** P2 — every approval, ask, trust gate and uncertain resume
- **agent:** kiso 0.16.3
- **found by:** the nineteen-screen audit against design §4
- **status:** FIXED (0.16.4 working tree)

## The measurement

Six status strings across four files opened with `▸`:

```
▸ run paused            ▸ project trust
▸ uncertain execution   ▸ unanswered question
▸ a question for you    ▸ asked the model for safer options
```

The checklist's active item also opens with `▸`, and does so on the
same screen during a paused turn.

## The cause

Design §4 settles `⏸` as *"it needs you: an approval or a question is
pending"* and §4.2 states the rule these strings break: *"One mark, one
meaning, everywhere. A mark that means two things is worse than two
marks."* The `▸` strings predate that table; nothing swept them when it
landed.

The distinction is not cosmetic. `▸` says *here*; `⏸` says *nothing
moves until you answer* — which is the fact a paused run has to convey,
and the fact §4.3's durability sentence is built on.

## The fix

All six become `⏸`. `▸` keeps its one meaning: the checklist's current
item. The tests that pinned the historical literals carry a declared
supersession naming the ruling.
