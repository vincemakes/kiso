# 0.50.1 — release report (APPROVED)

**A patch for 0.50.0's foreground ceiling.**

- **`kiso -p` runs without the foreground ceiling.** A `-p` run has nobody
  watching and stops its tasks when it ends, so 0.50.0's five-minute
  ceiling could promote a long check and then stop it with the turn.
- **A promoted task's runtime counts from the command's start.**
- **A wait cut at the ceiling says so,** to the model and on the terminal.

The first request is **byte-identical** to 0.50.0's.

- **Candidate:** `2286a5cc`, "chore: release 0.50.1", on main `444e624f`
  (#324); PR #325. The 17 tarballs were packed in a fresh worktree
  (`npm ci` before any build) after `npm run check` exited 0.
- **Lockstep:** a fix, so a PATCH; 17 packages.
- **Kernel:** unchanged; kiso-core is byte-identical to 0.50.0.

## For hosts

### Action required

**None.**

### Observable behaviour changes

- **`kiso -p`** keeps the model's own `foregroundMs`. The interactive CLI,
  the library default (300,000 ms) and every host are unchanged.
- **A promoted task's reported runtime** (`task_stop`, the end notice,
  `/tasks`) includes its foreground part.
- **The promotion text** gains `(the limit; you asked N ms)` when the
  ceiling cut a longer asked wait. A host that parses it should re-check.
- **Tool schemas and descriptions** are byte-identical to 0.50.0.
- **Packages:** 3 of the 17 differ beyond `package.json`: kiso-code,
  kiso-runtime and kiso-tools-node.
