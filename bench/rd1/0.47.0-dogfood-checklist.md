# 0.47.0 — dogfood checklist (for the owner's manual pass)

The release rule: after the publish, the agent runs one real-model session
on a real task, and the owner runs an independent pass. Both go into the
record before 0.47.0 is APPROVED.

0.47.0 is the Graphite TUI: the whole terminal surface is new; the pipe's
bytes are not. Use your daily terminal (Apple Terminal), at its usual
size, then once at 80×24.

Your `~/.kiso/config.json` sets `"mode": "bypass"`, so nothing asks by
default. The steps that need a question say to start with
`kiso --mode default`.

```
npm install -g @vincemakes/kiso-code@0.47.0
kiso --version        # 0.47.0
```

## A. The opening and the title

1. `kiso` in a project. The wordmark, the tagline and the version; beside
   it (≥ 96 columns) or below it, what loaded: `SESSION <id> · new`,
   `RULES`, `SKILLS`, `MCP`, `EXTENSIONS 4 · mcp, skills, subagent, ask`.
   No `session <id>` line above it.
2. The window's title reads `kiso — <folder>`; while kiso waits for you,
   `kiso · needs you — <folder>`; after `/name x`, `kiso · x — <folder>`.
3. Under 20 rows the opening is one line.

## B. The transcript

1. Your words sit on a warm block; the answer is the unmarked text.
2. Each call is one card: blue while it runs and when it worked, red when
   it failed, gold when it waits for you. The outcome (`exit 0 · 4 lines ·
   1.2s`) sits at the head's right.
3. A long shell command folds under its head; long output shows its tail
   with `… N earlier lines   ctrl+o expands`. `ctrl+o` expands every card;
   again collapses.
4. An edit shows its diff in the card.
5. Markdown: headings, lists, code in blue, tables.
6. `!ls` sends the output to the model; `!!ls` shows it only (`not
   sent`).
7. Thinking shows in grey italic; `ctrl+t` hides and shows it.

## C. The bar and the live row

1. The bar under the input: the mode, `/mode to switch`, the model and
   effort, `ctx ▆▆▆▆ N%` (the cells fill; gold past the soft tier), tok/s,
   the branch and the folder.
2. While a run is live, the row above the input: `working Ns · ↓ tokens`,
   and the keys `esc stop · ⏎ steer · alt+⏎ redirect` (`ctrl+b background`
   while a long command can be moved).
3. Type while it runs: the line steers the run; `alt+⏎` redirects.

## D. The panels and lists

1. `/` opens the command list (8 rows, filter by typing, Enter completes,
   the next Enter sends). `/skill` typed in full runs `/skill`.
2. `@` opens the file picker.
3. `/model`, `/mode`, `/settings`: one band each; `/mode` picks by digit.
4. Start `kiso --mode default` and ask for a file to be written: the
   approval panel names the call once, with `esc denies`. Answer "deny" so
   nothing is saved; a "don't ask again" answer would write a rule into
   `~/.kiso/` that you would then delete by hand.
5. A model question (ask the model to ask you something): the question
   panel; the selected option opens into its whole description.

## E. The sheets

`/status`, `/context`, `/skills`, `?` (the keys), `/help`: each a sheet over
the input, `esc closes · typing goes to the input`.

## F. Sessions and the small commands

1. `/resume`: a table, the selected row opens; `/name <words>`.
2. `/clear` leaves `SESSION <new id> · /resume <old> returns`.
3. `/think`, `/last` (one `THINKING` / `LAST CALL` block), `/rewrap`
   (`REWRAPPED …`), `/copy`.
4. A command typed wrong (`/mode bogus`) answers in one row, no brackets.

## G. Tasks

1. Ask for a long command in the background (`sleep 30` in the
   background): the bar shows `● 1 task running`.
2. When it ends, a `TASK t1 exited 0 · sleep 30` row.
3. `/tasks` → the task → show its output: a sheet.

## H. Compaction

1. `/compact` on a long session: the live row reads `compacting · manual ·
   N rounds · ~Nk → ▆▆▆▆▆▆ … · Ns`, then `COMPACTED …`.
2. Optional (needs a long session past the hard tier): a compaction in
   the middle of a run shows `compacting · auto` while the summary runs,
   then `COMPACTED mid-run · ~180k → ~22k · ctx now 11%`.

## I. What would be a finding

- A row wider than the terminal, a seam or a gap in a block, a frame that
  flickers, text left behind after a resize.
- Anything that reads as pre-Graphite: a bracketed reply at column 0,
  `--- … ---` rules, a `session <id>` line on screen.
- A surface that is slow to appear or to answer a key.
- Anything that behaves differently from 0.46.x in a pipe (`kiso -p …`).
