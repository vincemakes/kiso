## What is in it

PR #116, four commits, one per item of the plan (kiso-doc
`release-0406-plan-2026-09-23.md`):

| item | what changed |
|---|---|
| `/model` rows | the picker and the typed list carry availability (`unavailable`, whole) and `current`, not the window: the owner's 0.40.5 dogfood read the `ctx 1M (registry)` column as noise on every row. The window is in `/status` and `/settings` |
| hidden thinking | ctrl+t hides every thinking block — the open one included, from its first character — to one italic `thinking…` line (`thinking… · /think` once settled); the record keeps every word. Default shown. The choice is remembered in `<KISO_HOME>/preferences.json` (kiso-owned, 0600), never in config.json |
| `/settings` | read-only: each setting in force, the layer it came from (flag > env > project config > user config > default, else "set in this session"), and how to change it. Offered by `/` and named by `/help` |
| `kiso login --endpoint <url>` | a gateway's key, stored under `endpoint:<origin>` and sent to that origin alone (not another port, scheme, host or subdomain); used before the profile's env var, the order a vendor key takes; a vendor's own origin is refused. So a gateway profile starts from plain `kiso`. `kiso logout --endpoint`, `kiso auth` lists it masked |
