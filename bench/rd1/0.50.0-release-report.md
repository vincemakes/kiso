# 0.50.0 — release report (APPROVED)

**Tools that recover less and say what happened.**

- **An absolute path inside the workspace is admitted.** A model that
  names a file this way is no longer refused.
- **A refused edit batch says nothing was written.**
- **A long foreground command moves to the background at five minutes.**
- **The base prompt is the leaner P1.3.** The edit tools no longer ask the
  model for a revision: the host binds the one it last saw.

The first request is **81 tokens smaller** than 0.49.0's.

    landed and the bump was moved onto it. The repack is **17/17 sha256

- **Lockstep:** new capability, so a MINOR under 0.x; 17 packages.

## For hosts

### Action required

**None.**

### Observable behaviour changes

- **Absolute in-workspace paths** are admitted by read_file, write_file,
  edit_file, list_dir and search_text.
- **A foreground wait over five minutes** promotes the command to a task
  at five minutes.
- **The overwrite and batch refusal texts changed.** A host that parses
  them should re-check.
- **The base system prompt is P1.3.**
- **The skills index budget** is 3,000 chars.
- **Packages:** 5 of the 17 differ beyond `package.json`: kiso-code,
  kiso-tools-node, kiso-tui, kiso-tui-cells and kiso-skills-ext. The other
  12, kiso-core and kiso-runtime among them, are byte-identical apart from
  their `package.json`.

### New optional capabilities

- **`WorkspaceToolsOptions.limits.maxForegroundMs`:** the longest
  foreground wait, default 300,000. 0 keeps the model's value.
- **`WorkspaceToolsOptions.observedRevision`:** when supplied, the edit and
  write schemas drop `expectedRevision`, and the host binds the revision
  the model last observed.

## Findings

- **REL-0500-F1:** T6 moved −26.5 points against the reference since
  0.49.0's column. Several things changed at once and their effects are not
  separated:
  - kiso's P1.3 prompt and leaner schemas;
  - the reference's 1.1.0 → 1.2.0;
  - the route and meter;
  - variance at n = 6.
- **REL-0500-F2:** the release script `scripts/demo-kill9.sh` had not
  followed #311:
  - its scripted edits still sent `expectedRevision`, so the edits were
    refused at validation;
  - its kill predicate counted two executions, so the added reads
    satisfied it too early.

  Fixed in #322 before the gate resumed. The product's own kill -9 test
  was green throughout.
- **REL-0500-F3:** the gate machine's `/private/tmp` was swept at midnight
  and removed the gate's helper tools. The smoke checker was rebuilt (the
  prefix and version as environment variables) and re-run on the kept
  smoke leg. Gate tools now belong outside `/tmp`.
- **REL-0500-F4 (from the owner's dogfood):** asked "who are you", the
  model, DeepSeek V4.1 Flash, answered that it was Claude.
  - The base prompt says the assistant runs on Kiso and names no model, so
    the model guesses its identity from training.
  - Every metered request was served by `deepseek/deepseek-v4.1-flash`.
  - Stating the bound model in the prompt is a prompt change and carries
    a cost on `/model` switches (the prompt is byte-stable per session). It
    is left for a measured round.
