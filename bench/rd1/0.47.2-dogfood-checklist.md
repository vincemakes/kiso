# 0.47.2 — dogfood checklist (for the owner's manual pass)

The release rule: after the publish, the agent runs one real-model session
on a real task, and the owner runs an independent pass. Both go into the
record before 0.47.2 is APPROVED.

0.47.2 is one fix: `list_dir` with a glob walks on the search worker, under
`search_text`'s budget (#279). It froze kiso for 11 s when the model
searched a home directory by name. Nothing else moved.

```
npm install -g @vincemakes/kiso-code@0.47.2
kiso --version        # 0.47.2
```

## A. A search from your home directory

1. `cd ~`, then `kiso`.
2. Ask where one of your projects is, by name (`where is the <name>
   project on this machine?`), so the model lists the tree with a glob.
3. While it searches, the working row's mark keeps moving and its seconds
   keep counting; esc stops the run at once if you press it.
4. If the walk is long, its `LIST` card ends with `the walk stopped after
   20000 files — narrow the path` or `the walk stopped — its budget
   elapsed …` rather than going quiet.

## B. What would be a finding

- The working row standing still for more than a second during a run.
- A `LIST` card whose paths begin with `../`.
- Anything that reads differently from 0.47.1 other than A.
